# Tight-cropped standalone sprites

This is a non-destructive copy of the top-down pack. 120 individual transparent sprites (buildings, decorations, and vehicles) were square-cropped to their visible pixels plus 12px padding.

- All original file paths and filenames are unchanged.
- Terrain, road, and rail tiles are untouched so they remain seamless.
- Source and transparent sheets are untouched; use the individual `sprites/` files for the tightened art.
- `trim_manifest.json` records each original crop rectangle in case placement anchors need to be preserved.
