## Product Purpose

An incremental town-building game with a seed-to-cigar production chain,
land expansion, deliveries, research, decorations, and prestige tiers.
These facts come from the existing application.

## Capabilities and Constraints

Nuxt, Vue, Pinia, and Canvas 2D. Local saves and the existing economy must
survive visual changes. The requested overhaul is more 2D and animated.
The user requires fewer than 50 Higgsfield credits and economical Codex use.
Higgsfield is connected. GPT Image 2.5 rejected generation on the free plan;
Z Image successfully generated terrain for 0.15 credits. Object animation is
local Canvas 2D. Account-level OpenAI allowance usage is not exposed here.

## Brand Commitments
